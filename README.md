# AREDN Monitor

AREDN Monitor, AREDN ağlarını merkezi olarak izlemek ve yönetmek için geliştirilen açık kaynaklı bir platformdur.

## Hedefler

- Node Monitoring
- Link Quality
- Harita
- Telegram Alarm
- REST API
- Docker Kurulumu
- Plugin Desteği
- ACE Platform ile tam uyumluluk

## Gereksinimler

- Ubuntu 24.04 LTS
- Docker Engine
- Docker Compose
